What does THE DESK actually do?

It takes real market data, computes indicators, gives each agent a distinct framework, produces a structured call, and later scores that call over time. The goal is a public, verifiable desk—not a static token page.

Are the agents only visual characters?

No. The visual layer is only the presentation. Underneath, each agent is meant to have different rules, then a bot will lock calls and update league tables and track records automatically.

What happens if live data is missing?

The page says WAITING FOR LIVE DATA. It does not invent prices, charts, fills or returns.

Where do the bot and competition fit?

That comes right after this visual layer: data ingestion, signal engine, locked calls, scoring bot, then public league/record. The token side comes later.
