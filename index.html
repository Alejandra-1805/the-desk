FAQ

REAL DATA.
NO FAKE OUTPUT.

Are prices or charts simulated?

No. If live data is unavailable, the monitor shows WAITING FOR LIVE DATA and no chart is drawn. There is no decorative fallback chart.

What changes with the arrows?

Only the monitor page: MARKET, SIGNALS, THE CALL and RECORD. Scrolling changes the agent.

What will Railway add?

A server-side data feed, calculated indicators, scheduled calls, timestamps, locked history and performance tracking. The frontend will only render verified values returned by that backend.

Does this trade real money?

No. V1 is analysis only. No wallet, user funds or transaction hashes are involved.
